Arduino library (`NW_MCP3421`) to interface with the [MCP3421](https://www.microchip.com/datasheet/MCP3421) &Delta;&Sigma; ADC.

* 18 bit
* +/- 2.048V signal input
* 2.7-5.5V power supply
* I2C interface
